# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its text at that address is the code of conduct of this project; it applies in the
repository, its issues, pull requests and discussions, and wherever someone speaks for
the project.

In short: be respectful, assume good faith, criticise the work and not the person, and
accept that maintainers may edit or remove contributions and comments that do not fit.

## Reporting

Report behaviour that breaks the code of conduct to <contact@vispek.cn>. Reports are
read by the maintainers at VISPEK Technology Co., Ltd, are kept confidential, and are
answered. Enforcement follows the guidelines of the Contributor Covenant.
